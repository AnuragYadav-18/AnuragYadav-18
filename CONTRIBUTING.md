# Contributing

Thanks for considering a contribution! Some simple guidelines to make the process fast and pleasant:

- Fork the repository and create a feature branch named `feat/short-description` or `fix/short-description`.
- Write clear, concise commit messages.
- Add or update tests where applicable.
- Open a Pull Request with a description of the changes and the motivation.
- Be responsive to review comments — I'll try to review within 48 hours.

If you're unsure where to start, check issues labeled `good first issue` or `help wanted`.
